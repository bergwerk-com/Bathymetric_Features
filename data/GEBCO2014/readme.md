# GEBCO 30 Arc-Second Bathymetry Dataset

## Quick Download Links

**GEBCO_2014 Grid (30 arc-second resolution):**

- **Website:** https://www.bodc.ac.uk/data/documents/nodb/301801/
- **Main Dataset:** https://www.bodc.ac.uk/data/open_download/gebco/GEBCO_30SEC/zip/ (1.2 GB)
- **Source Identifier Grid:** https://www.bodc.ac.uk/data/open_download/gebco/GEBCO_SID/zip/ (32 MB)

## Dataset Info

- **Resolution:** 30 arc-second intervals (~1 km)
- **Coverage:** Global ocean and land terrain
- **Format:** NetCDF
- **Last Updated:** April 2015
- **License:** Public domain

## Alternative Download

For custom regions: https://download.gebco.net/

## Citation

```
GEBCO Compilation Group (2015) GEBCO_2014 Grid, version 20150318
```

## Notes

- SID Grid shows data source type (soundings, interpolation, etc.)
- This is a historical dataset - newer 15 arc-second grids available
- Based on ship soundings + satellite gravity interpolation
