# GEBCO 15 Arc-Second Bathymetry Dataset

## Quick Download Links

**GEBCO_2025 Grid (15 arc-second resolution):**

- **Website:** https://www.gebco.net/data-products/gridded-bathymetry-data
- **Main Dataset:** https://dap.ceda.ac.uk/bodc/gebco/global/gebco_2025/ice_surface_elevation/netcdf/gebco_2025.zip?download=1 (7.5 GB)

## Dataset Info

- **Resolution:** 15 arc-second intervals
- **Coverage:** Global ocean and land terrain
- **Format:** NetCDF
- **Last Updated:** August 2025
- **License:** Public domain

## Alternative Download

For custom regions: https://download.gebco.net/
